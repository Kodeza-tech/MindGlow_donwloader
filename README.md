1. Baixe o arquivo mindglow.apk atraves do link acima.
2. Abra o arquivo baixado no seu dispositivo Android.
3. Se solicitado, autorize a instalacao de fontes desconhecidas nas configuracoes do sistema.
4. Conclua a instalacao e abra o aplicativo.
